# 조직도 (Organization)

`nav='org'` — 부서 트리, 사용자(엔지니어/매니저), 직급 마스터.

## 1. 메뉴 개요

- 사용자: 모든 사용자(조회), HR/매니저(편집)
- 책임: 부서 자기참조 트리, 사용자 CRUD, 직급 마스터(POSITIONS — 도입 결정 후)
- **이미 DB 연동 완료** — Phase 1에서는 표준화 + Repository 분리 + 기술서

## 2. 화면/UX 흐름

1. 진입 → 좌측 부서 트리 + 우측 사용자 목록
2. 부서 클릭 → 해당 부서 + 자손 부서의 사용자 표시
3. 트리/차트 모드 토글
4. 사용자 카드 → DM 채널 열기(메신저 연동), 프로필 상세
5. 부서/사용자 추가/편집 → 모달

## 3. 데이터 모델

기존 테이블(`backend/src/orgCustomerSchema.js`):

```sql
DEPARTMENTS (
  DEPT_ID NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY,
  PARENT_DEPT_ID NUMBER,                            -- 자기참조
  NAME VARCHAR2(200 CHAR) NOT NULL,
  SORT_ORDER NUMBER DEFAULT 0 NOT NULL,
  ENABLED NUMBER(1) DEFAULT 1 NOT NULL,
  ...
  CONSTRAINT FK_DEPARTMENTS_PARENT FOREIGN KEY (PARENT_DEPT_ID) REFERENCES DEPARTMENTS(DEPT_ID)
)

USERS (
  USER_ID NUMBER NOT NULL,                          -- 외부 ID(IDENTITY 미사용)
  USERNAME VARCHAR2(80 CHAR) NOT NULL UNIQUE,
  NAME VARCHAR2(200 CHAR) NOT NULL,
  POSITION_NAME VARCHAR2(100 CHAR),                 -- 자유 입력(POSITIONS 도입 시 마스터화)
  DEPT_ID NUMBER,
  EMAIL VARCHAR2(200 CHAR),
  PHONE VARCHAR2(40 CHAR),
  ENABLED NUMBER(1) DEFAULT 1 NOT NULL,
  ...
  CONSTRAINT FK_USERS_DEPT FOREIGN KEY (DEPT_ID) REFERENCES DEPARTMENTS(DEPT_ID)
)
```

신규(선택):
```sql
POSITIONS (
  POSITION_ID VARCHAR2(40 CHAR) NOT NULL,
  POSITION_NAME VARCHAR2(100 CHAR) NOT NULL,
  SORT_ORDER NUMBER DEFAULT 0 NOT NULL,
  ENABLED NUMBER(1) DEFAULT 1 NOT NULL,
  CONSTRAINT PK_POSITIONS PRIMARY KEY (POSITION_ID)
)
```

## 4. API 엔드포인트 (이미 동작)

| 메서드 | 경로 | 비고 |
|---|---|---|
| GET | `/api/org/departments` | 트리(자기참조) |
| POST/PATCH/DELETE | `/api/org/departments[/:id]` | CRUD(소프트 삭제) |
| GET | `/api/org/users?deptId=&q=` | 사용자 목록 |
| POST/PATCH/DELETE | `/api/org/users[/:id]` | CRUD |
| GET | `/api/org/positions` | (신규, POSITIONS 도입 시) |

Phase 1에서 envelope 마이그레이션 + 응답 표준화.

## 6. 주요 비즈니스 로직

- **자손 부서 조회**: 현재 프론트에서 `getDescendantDeptIds`로 평탄화. Oracle 측 `CONNECT BY PRIOR`로 옮기거나 그대로 유지(소규모면 무방)
- **부서 비활성화 시 검증**: 하위 활성 부서/사용자 있으면 거절(현 `deleteDepartment`가 이미 처리, `orgCustomerRepository.js:124-171`)
- **DM 열기**: 사용자 카드의 채널 이동 — messaging 도메인과 연동(별도 작업)
- **정렬**: 한국어 정렬 시 `localeCompare(a, b, 'ko')`
