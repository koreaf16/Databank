# 작업현황표 (Matrix)

`nav='mat'` — 고객별·서비스별·월별 정기점검 진행 매트릭스. 한 셀이 한 달의 점검 상태를 표시.

## 1. 메뉴 개요

- 사용자: 매니저(전체), 엔지니어(본인 담당)
- 책임: 정기점검 계획(반기 단위) 등록, 월별 셀 상태 추적, 지원이력과 자동 연동
- 셀 상태: pending(미진행) / done(완료) / urgent(지연/긴급)

## 2. 화면/UX 흐름

1. 진입 → 연도 + 반기(상/하) + 범위(scope: me|all) 선택
2. 매트릭스 표 — 행: 고객사+서비스, 열: 6개월(1~6 또는 7~12)
3. 셀 클릭 → 슬라이드 패널(상세 + 연결된 SUPPORT_HISTORIES)
4. 필터 — 적색만(urgent) 보기
5. 정기점검 계획은 관리설정 또는 별도 모달에서 등록

## 3. 데이터 모델

```sql
ROUTINE_PLANS (
  PLAN_ID NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY,
  CUSTOMER_ID NUMBER NOT NULL,
  SERVICE_NAME VARCHAR2(200 CHAR) NOT NULL,
  PERIOD_YEAR NUMBER NOT NULL,
  PERIOD_HALF NUMBER NOT NULL,                      -- 1: 상반기, 2: 하반기
  TARGET_FREQ VARCHAR2(40 CHAR),                    -- monthly | quarterly | semiannual
  ENABLED NUMBER(1) DEFAULT 1 NOT NULL,
  CONSTRAINT PK_ROUTINE_PLANS PRIMARY KEY (PLAN_ID),
  CONSTRAINT FK_RP_CUSTOMER FOREIGN KEY (CUSTOMER_ID) REFERENCES CUSTOMERS(CUSTOMER_ID),
  CONSTRAINT UK_RP_UNIT UNIQUE (CUSTOMER_ID, SERVICE_NAME, PERIOD_YEAR, PERIOD_HALF)
)

ROUTINE_PLAN_CELLS (
  PLAN_ID NUMBER NOT NULL,
  PERIOD_MONTH NUMBER NOT NULL,                     -- 1~12
  STATUS VARCHAR2(20 CHAR) DEFAULT 'pending' NOT NULL, -- pending | done | urgent
  HISTORY_ID VARCHAR2(40 CHAR),                     -- SUPPORT_HISTORIES 연결(완료 시)
  UPDATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT PK_RPC PRIMARY KEY (PLAN_ID, PERIOD_MONTH),
  CONSTRAINT FK_RPC_PLAN FOREIGN KEY (PLAN_ID) REFERENCES ROUTINE_PLANS(PLAN_ID) ON DELETE CASCADE,
  CONSTRAINT FK_RPC_HISTORY FOREIGN KEY (HISTORY_ID) REFERENCES SUPPORT_HISTORIES(HISTORY_ID)
)
```

## 4. API 엔드포인트

| 메서드 | 경로 | 비고 |
|---|---|---|
| GET | `/api/matrix?year=&half=&scope=me\|all` | 6개월 셀 LEFT JOIN |
| POST | `/api/matrix/plans` | 정기점검 계획 등록 |
| PATCH | `/api/matrix/plans/:id` | 수정 |
| DELETE | `/api/matrix/plans/:id` | 비활성화 |
| PATCH | `/api/matrix/cells/:planId/:month` | 셀 상태 변경 |

응답 예시:
```json
{
  "ok": true,
  "data": [
    { "planId": 1, "customer": "...", "service": "Oracle 19c",
      "cells": [
        { "month": 1, "status": "done", "historyId": "H-000123" },
        { "month": 2, "status": "pending", "historyId": null }
      ] }
  ]
}
```

## 6. 주요 비즈니스 로직

- **셀 자동 done 갱신**: `services/matrixSyncService.js`가 SUPPORT_HISTORIES 등록 시 호출 — 같은 (customer, service, month)에 해당하는 ROUTINE_PLAN_CELLS.STATUS='done' + HISTORY_ID 연결
- **urgent 자동 표시**: 월말이 지났는데 done이 아니면 urgent로 (배치 또는 SELECT 시 계산)
- **scope=me**: 사용자가 담당자(CUSTOMER_ASSIGNMENTS)인 고객사만 필터
- **반기 단위 표시**: half=1이면 1~6월, half=2면 7~12월

## 7. 의존성

- 1.3 지원이력(HISTORY_ID로 셀 자동 갱신)
- 1.8 고객사 + CUSTOMER_ASSIGNMENTS(scope=me 필터)
- 1.9 관리설정의 SERVICE_MASTER(SERVICE_NAME 마스터화 시)
