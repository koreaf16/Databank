# 일정관리 (Calendar)

`nav='cal'` — 엔지니어 일정(정기점검/기술지원/장애대응/회의/설치)과 직출/직퇴 알림을 관리.

## 1. 메뉴 개요

- 사용자: 엔지니어, 매니저
- 책임: 주간/월간 일정 등록·조회·수정, 직출/직퇴 알림(GPS 위치 포함)
- 핵심 엔티티: EVENTS, EVENT_PARTICIPANTS, ATTENDANCE_NOTICES

## 2. 화면/UX 흐름

1. 진입 → 이번 주 주간 뷰
2. 셀 클릭 → 새 일정 등록 모달
3. 기존 일정 행 클릭 → 상세 + 수정/삭제
4. 좌측 필터: 고객사, 엔지니어, 유형(routine/tech/incident/meeting/install), 방식(onsite/remote)
5. 직출/직퇴 알림 별도 진입 — 모바일에서 등록되며 매니저가 검토

## 3. 데이터 모델

```sql
EVENTS (
  EVENT_ID NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY,
  TITLE VARCHAR2(200 CHAR) NOT NULL,
  EVENT_TYPE VARCHAR2(20 CHAR) NOT NULL,           -- routine | tech | incident | meeting | install
  CUSTOMER_ID NUMBER NULL,                          -- 내부 회의는 NULL
  SERVICE_NAME VARCHAR2(200 CHAR) NULL,
  START_AT TIMESTAMP NOT NULL,
  END_AT TIMESTAMP NOT NULL,
  METHOD VARCHAR2(20 CHAR),                         -- onsite | remote
  MEMO CLOB,
  CREATED_BY NUMBER,                                -- USER_ID
  ENABLED NUMBER(1) DEFAULT 1 NOT NULL,
  CREATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  UPDATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT PK_EVENTS PRIMARY KEY (EVENT_ID),
  CONSTRAINT FK_EVENTS_CUSTOMER FOREIGN KEY (CUSTOMER_ID) REFERENCES CUSTOMERS(CUSTOMER_ID),
  CONSTRAINT FK_EVENTS_USER FOREIGN KEY (CREATED_BY) REFERENCES USERS(USER_ID)
)

EVENT_PARTICIPANTS (
  EVENT_ID NUMBER NOT NULL,
  USER_ID NUMBER NOT NULL,
  ROLE VARCHAR2(30 CHAR),                           -- owner | participant
  CONSTRAINT PK_EVENT_PARTICIPANTS PRIMARY KEY (EVENT_ID, USER_ID),
  CONSTRAINT FK_EP_EVENT FOREIGN KEY (EVENT_ID) REFERENCES EVENTS(EVENT_ID) ON DELETE CASCADE,
  CONSTRAINT FK_EP_USER FOREIGN KEY (USER_ID) REFERENCES USERS(USER_ID)
)

ATTENDANCE_NOTICES (
  NOTICE_ID VARCHAR2(40 CHAR) NOT NULL,
  STAFF_USER_ID NUMBER NOT NULL,
  KIND VARCHAR2(20 CHAR) NOT NULL,                  -- direct_start | direct_end
  ATTEND_DATE DATE NOT NULL,
  EFFECTIVE_TIME VARCHAR2(5 CHAR) NOT NULL,         -- 'HH:MM'
  CUSTOMER_ID NUMBER NULL,
  SITE_NAME VARCHAR2(200 CHAR),
  WORK_TITLE VARCHAR2(200 CHAR),
  MEMO CLOB,
  MANUAL_LOCATION_TEXT VARCHAR2(500 CHAR),
  GPS_LAT NUMBER, GPS_LNG NUMBER, GPS_ACCURACY NUMBER,
  GPS_CAPTURED_AT TIMESTAMP,
  GPS_CONSENT NUMBER(1),
  STATUS VARCHAR2(30 CHAR) NOT NULL,                -- notified | recorded | needs_correction | cancelled
  MANAGER_USER_ID NUMBER,
  MANAGER_SEEN_AT TIMESTAMP,
  MANAGER_MEMO CLOB,
  CREATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  UPDATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT PK_ATTENDANCE_NOTICES PRIMARY KEY (NOTICE_ID),
  CONSTRAINT FK_AN_STAFF FOREIGN KEY (STAFF_USER_ID) REFERENCES USERS(USER_ID),
  CONSTRAINT FK_AN_CUSTOMER FOREIGN KEY (CUSTOMER_ID) REFERENCES CUSTOMERS(CUSTOMER_ID)
)
```

인덱스 후보: `EVENTS(START_AT, END_AT)`, `EVENTS(CUSTOMER_ID)`, `ATTENDANCE_NOTICES(STAFF_USER_ID, ATTEND_DATE)`.

## 4. API 엔드포인트

| 메서드 | 경로 | 비고 |
|---|---|---|
| GET | `/api/calendar/events?from=&to=&customerId=&engineerId=&type=&method=` | 주간/월간 조회 |
| POST | `/api/calendar/events` | 등록(EVENT + PARTICIPANTS 트랜잭션) |
| PATCH | `/api/calendar/events/:id` | 수정 |
| DELETE | `/api/calendar/events/:id` | 비활성화(소프트) |
| GET | `/api/attendance/notices?staffUserId=&from=&to=&status=` | 직출/직퇴 |
| POST | `/api/attendance/notices` | 등록(모바일에서 호출) |
| PATCH | `/api/attendance/notices/:id` | 매니저 확인/수정 |

## 6. 주요 비즈니스 로직

- 주간 범위: 월요일 00:00 ~ 일요일 23:59:59 (KST 기준)
- 하루 셀당 표시: START_AT~END_AT 막대, 길이는 분 단위 비례
- 직출/직퇴 STATUS 흐름: `notified` → `recorded` 또는 `needs_correction` → 매니저 검토 후 `recorded`/`cancelled`
