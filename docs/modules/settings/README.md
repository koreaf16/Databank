# 관리설정 (Settings)

`nav='set'` — 시스템 마스터 데이터 관리. 6개 탭(서비스/체크리스트/AI 모델/RBAC/보고서 템플릿/감사로그).

## 1. 메뉴 개요

- 사용자: 시스템 관리자, 매니저
- 책임: 운영에 필요한 마스터/구성을 한 곳에서 관리
- 탭별 책임 분리:
  - 서비스 마스터(SERVICE_MASTER) — 점검 대상 서비스 카탈로그
  - 체크리스트(CHECKLISTS) — 점검 항목 묶음
  - AI 모델(AI_PROVIDERS / AI_MODELS / AI_USE_CASES) — LLM 카탈로그
  - 보고서 템플릿(REPORT_MASTER_TEMPLATES) — 이미 DB 연동
  - RBAC(ROLES / PERMISSIONS / ROLE_PERMISSIONS) — 권한 매트릭스
  - 감사로그(AUDIT_LOG) — 변경 이력

## 2. 화면/UX 흐름

1. 진입 → 좌측 탭 6개
2. 각 탭: 좌측 목록, 우측 상세/편집
3. 추가/수정/삭제 — 모달 또는 인라인
4. 감사로그 탭 — 읽기 전용, 필터(actor, action, target, 기간)

## 3. 데이터 모델

```sql
SERVICE_MASTER (
  SERVICE_MASTER_ID VARCHAR2(40 CHAR) NOT NULL,
  NAME VARCHAR2(200 CHAR) NOT NULL,
  CATEGORY VARCHAR2(80 CHAR),                       -- DB | OS | NW | SEC | APP
  DEFAULT_FREQ VARCHAR2(40 CHAR),                   -- monthly | quarterly | semiannual
  ENABLED NUMBER(1) DEFAULT 1 NOT NULL,
  CREATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  UPDATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT PK_SERVICE_MASTER PRIMARY KEY (SERVICE_MASTER_ID)
)

SERVICE_MASTER_VERSIONS (
  SERVICE_MASTER_ID VARCHAR2(40 CHAR) NOT NULL,
  VERSION VARCHAR2(40 CHAR) NOT NULL,
  CONSTRAINT PK_SMV PRIMARY KEY (SERVICE_MASTER_ID, VERSION),
  CONSTRAINT FK_SMV_SM FOREIGN KEY (SERVICE_MASTER_ID) REFERENCES SERVICE_MASTER(SERVICE_MASTER_ID) ON DELETE CASCADE
)

CHECKLISTS (
  CHECKLIST_ID VARCHAR2(40 CHAR) NOT NULL,
  NAME VARCHAR2(200 CHAR) NOT NULL,
  VERSION VARCHAR2(40 CHAR),
  STATUS VARCHAR2(20 CHAR) DEFAULT 'draft' NOT NULL, -- draft | active | archived
  SCOPE VARCHAR2(40 CHAR),                          -- service | customer | customerService
  SERVICE_MASTER_ID VARCHAR2(40 CHAR),
  CUSTOMER_ID NUMBER,
  PAYLOAD CLOB,                                     -- 항목 직렬화(JSON)
  ENABLED NUMBER(1) DEFAULT 1 NOT NULL,
  CREATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  UPDATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT PK_CHECKLISTS PRIMARY KEY (CHECKLIST_ID),
  CONSTRAINT FK_CL_SM FOREIGN KEY (SERVICE_MASTER_ID) REFERENCES SERVICE_MASTER(SERVICE_MASTER_ID),
  CONSTRAINT FK_CL_CUSTOMER FOREIGN KEY (CUSTOMER_ID) REFERENCES CUSTOMERS(CUSTOMER_ID)
)

AI_PROVIDERS (PROVIDER_ID PK, NAME, COLOR, ENABLED)
AI_MODELS (MODEL_ID PK, PROVIDER_ID FK, NAME, USE_CASES_CSV, ENABLED, CREATED_AT)
AI_USE_CASES (USE_CASE_ID PK, NAME)

RBAC_ROLES (ROLE_ID PK, ROLE_NAME, DESCRIPTION, ENABLED)
RBAC_PERMISSIONS (PERMISSION_KEY PK, GROUP_KEY, NAME, DESCRIPTION)
RBAC_ROLE_PERMISSIONS (ROLE_ID, PERMISSION_KEY, PK 복합)

AUDIT_LOG (
  LOG_ID NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY,
  ACTOR_USER_ID NUMBER,
  ACTION VARCHAR2(80 CHAR),                         -- create | update | delete | login | ...
  TARGET_TYPE VARCHAR2(40 CHAR),                    -- customer | user | event | history | ...
  TARGET_ID VARCHAR2(80 CHAR),
  PAYLOAD CLOB,                                     -- 변경 전/후 (JSON)
  AT_TIME TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT PK_AUDIT_LOG PRIMARY KEY (LOG_ID),
  CONSTRAINT FK_AL_USER FOREIGN KEY (ACTOR_USER_ID) REFERENCES USERS(USER_ID)
)
```

기존: `REPORT_MASTER_TEMPLATES` (`backend/src/reportTemplateSchema.js`).

## 4. API 엔드포인트

| 메서드 | 경로 | 탭 |
|---|---|---|
| GET/POST/PATCH/DELETE | `/api/settings/service-master[/:id]` | 서비스 마스터 |
| GET/POST/PATCH/DELETE | `/api/settings/checklists[/:id]` | 체크리스트 |
| GET/POST/PATCH/DELETE | `/api/settings/ai-providers[/:id]` | AI(공급사) |
| GET/POST/PATCH/DELETE | `/api/settings/ai-models[/:id]` | AI(모델) |
| GET/POST/PATCH/DELETE | `/api/settings/ai-use-cases[/:id]` | AI(용도) |
| GET/POST/PATCH/DELETE | `/api/settings/rbac/roles[/:id]` | RBAC 역할 |
| GET/POST/PATCH/DELETE | `/api/settings/rbac/permissions[/:key]` | 권한 |
| PUT | `/api/settings/rbac/roles/:roleId/permissions` | 권한 매트릭스 갱신 |
| GET | `/api/settings/audit?actor=&action=&target=&from=&to=&page=` | 감사로그 |
| GET/POST/PATCH/DELETE | `/api/report-templates[/:id]` | 보고서 템플릿(기존) |

## 6. 주요 비즈니스 로직

- **체크리스트 SCOPE**: service(서비스 단위) / customer(고객사 단위) / customerService(고객×서비스 조합) — SCOPE에 따라 SERVICE_MASTER_ID 또는 CUSTOMER_ID 또는 둘 다 필수
- **권한 매트릭스 PUT**: 한 역할의 권한 목록을 통째로 교체 — DELETE all + INSERT N건 트랜잭션
- **감사로그**: 모든 도메인 변경 시 미들웨어 또는 서비스 레이어가 INSERT(현재 미구현, RBAC 도입 시 동시 적용)
- **AI 모델 USE_CASES_CSV**: 1:N 정규화 대신 CSV로 단순화 — 검색 빈도 낮음
