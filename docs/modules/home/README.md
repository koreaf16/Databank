# 홈 (Home)

`nav='home'` — 사용자가 로그인 후 처음 마주하는 대시보드. 다른 메뉴 데이터를 집계해 보여준다.

## 1. 메뉴 개요

- 사용자: 모든 사용자
- 책임: 이번 주 KPI, 오늘의 일정, 엔지니어별 진행률 요약
- 자체 데이터 없음 — `EVENTS`, `SUPPORT_HISTORIES`, `WEEKLY_REPORTS`, `USERS` 등을 집계

## 2. 화면/UX 흐름

1. 진입 — 좌측 네비 "홈" 클릭(또는 기본 진입)
2. KPI 카드들이 비동기 로드(이번 주 점검 건수, 미작성 보고서, 진행 중 이력 등)
3. 오늘의 일정이 시간 순으로 표시
4. 엔지니어별 진행률 — 부서/팀 단위 게이지
5. 핀 고정 빠른 이동(옵션) — 자주 가는 메뉴/페이지 단축

## 3. 데이터 모델

자체 테이블 없음. 옵션 테이블:

```
HOME_PINNED_QUICK_LINKS (
  PIN_ID NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY,
  USER_ID NUMBER NOT NULL,
  NAV VARCHAR2(20 CHAR) NOT NULL,
  LABEL VARCHAR2(80 CHAR),
  ORDER_NO NUMBER DEFAULT 0,
  CONSTRAINT PK_HOME_PINNED_QUICK_LINKS PRIMARY KEY (PIN_ID),
  CONSTRAINT FK_HPQL_USER FOREIGN KEY (USER_ID) REFERENCES USERS(USER_ID)
)
```

## 4. API 엔드포인트

| 메서드 | 경로 | 응답 핵심 |
|---|---|---|
| GET | `/api/home/summary?userId=` | 이번 주 KPI(점검/보고서/이력 카운트) |
| GET | `/api/home/today-schedule?date=` | 오늘 EVENTS 목록(EVENTS join CUSTOMERS) |
| GET | `/api/home/engineer-progress?weekStart=` | 사용자별 진행률 — 지원이력+보고서 집계 |
| GET | `/api/home/pinned-links?userId=` | 핀 고정 |
| POST | `/api/home/pinned-links` | 핀 추가 |
| DELETE | `/api/home/pinned-links/:id` | 핀 제거 |

응답 envelope 예시:
```json
{
  "ok": true,
  "data": {
    "thisWeek": { "totalEvents": 23, "doneHistories": 18, "pendingReports": 5 }
  }
}
```

## 6. 주요 비즈니스 로직

- **이번 주 KPI 계산**: `WEEK_START`(월요일 00:00) ~ `WEEK_END`(일요일 23:59) 범위로 EVENTS, SUPPORT_HISTORIES, WEEKLY_REPORTS 집계
- **엔지니어 진행률**: 사용자별 (등록 이력 시간 / 가동 가능 시간) — 가동률 도메인 로직과 동일 공식
- 시각 기준은 KST(서버 SYSTIMESTAMP)

## 7. 의존성

- 1.2 일정관리 → EVENTS 집계
- 1.3 지원이력 → SUPPORT_HISTORIES 집계
- 1.5 주간업무보고 → WEEKLY_REPORTS 집계
- 1.7 조직도 → USERS, DEPARTMENTS

다른 메뉴 데이터가 채워진 후 의미가 생기므로 Phase 1 마지막에 진행.
