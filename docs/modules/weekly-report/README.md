# 주간업무보고 (Weekly Report)

`nav='rep'` — 팀별 주간 업무 실적/계획 작성, 마스터 템플릿 기반 PDF 출력.

## 1. 메뉴 개요

- 사용자: 엔지니어(작성), 매니저(검토/PDF 출력)
- 책임: 한 팀의 한 주 보고서를 작성, 다음 주 일정 추가, PDF 다운로드
- 마스터 템플릿: 이미 DB 연동된 `REPORT_MASTER_TEMPLATES`(HTML/CSS/LLM 프롬프트 보관)

## 2. 화면/UX 흐름

1. 진입 → 팀 선택 + 주차 선택(기본: 이번 주)
2. 엔지니어 카드 N개(팀원 수만큼) — 각 카드에 이번 주 실적 + 다음 주 계획
3. "다음 주 일정 추가" → EVENTS 등록 모달(일정관리와 동일 모달 재사용)
4. "정기 일정" → ROUTINE_PLANS 자동 추출
5. "PDF 출력" → `/api/reports/render-pdf` 호출 → 다운로드

## 3. 데이터 모델

```sql
WEEKLY_REPORTS (
  REPORT_ID NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY,
  TEAM_ID VARCHAR2(40 CHAR),
  WEEK_START DATE NOT NULL,
  WEEK_END DATE NOT NULL,
  STATUS VARCHAR2(20 CHAR) DEFAULT 'draft' NOT NULL,-- draft | submitted | confirmed
  CREATED_BY NUMBER,
  TEMPLATE_ID VARCHAR2(100 CHAR),                    -- REPORT_MASTER_TEMPLATES.TEMPLATE_ID
  PAYLOAD CLOB,                                      -- 보고 본문(JSON 직렬화)
  CREATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  UPDATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT PK_WEEKLY_REPORTS PRIMARY KEY (REPORT_ID),
  CONSTRAINT FK_WR_USER FOREIGN KEY (CREATED_BY) REFERENCES USERS(USER_ID),
  CONSTRAINT FK_WR_TEMPLATE FOREIGN KEY (TEMPLATE_ID) REFERENCES REPORT_MASTER_TEMPLATES(TEMPLATE_ID)
)

WEEKLY_REPORT_ITEMS (
  ITEM_ID NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY,
  REPORT_ID NUMBER NOT NULL,
  ENGINEER_USER_ID NUMBER NOT NULL,
  ITEM_TYPE VARCHAR2(20 CHAR),                      -- work | routine | next_week
  EVENT_ID NUMBER,                                   -- 다음주 일정 연결
  HISTORY_ID VARCHAR2(40 CHAR),                      -- 실적(지원이력) 연결
  PAYLOAD CLOB,
  CONSTRAINT PK_WRI PRIMARY KEY (ITEM_ID),
  CONSTRAINT FK_WRI_REPORT FOREIGN KEY (REPORT_ID) REFERENCES WEEKLY_REPORTS(REPORT_ID) ON DELETE CASCADE,
  CONSTRAINT FK_WRI_USER FOREIGN KEY (ENGINEER_USER_ID) REFERENCES USERS(USER_ID)
)

TEAMS (
  TEAM_ID VARCHAR2(40 CHAR) NOT NULL,
  TEAM_NAME VARCHAR2(200 CHAR) NOT NULL,
  COLOR VARCHAR2(20 CHAR),
  PARENT_DEPT_ID NUMBER,                             -- DEPARTMENTS와 매핑(선택)
  ENABLED NUMBER(1) DEFAULT 1 NOT NULL,
  CONSTRAINT PK_TEAMS PRIMARY KEY (TEAM_ID),
  CONSTRAINT FK_TEAMS_DEPT FOREIGN KEY (PARENT_DEPT_ID) REFERENCES DEPARTMENTS(DEPT_ID)
)
```

## 4. API 엔드포인트

| 메서드 | 경로 | 비고 |
|---|---|---|
| GET | `/api/weekly-reports?weekStart=&teamId=` | 주차+팀 단위 조회 |
| GET | `/api/weekly-reports/:id` | 상세(REPORT + ITEMS) |
| POST | `/api/weekly-reports` | 등록(REPORT + ITEMS 트랜잭션) |
| PATCH | `/api/weekly-reports/:id` | 수정 |
| GET | `/api/teams` | 팀 마스터 |
| POST | `/api/reports/render-pdf` | PDF 렌더(envelope 우회, binary 응답) |

## 6. 주요 비즈니스 로직

- **주차 경계**: 월요일 00:00 KST → 일요일 23:59:59 KST
- **다음 주 일정 추가**: EVENTS 등록 + WEEKLY_REPORT_ITEMS의 `next_week` 항목으로 연결
- **이번 주 실적 자동 채움**: SUPPORT_HISTORIES 중 SUPPORT_STARTED_AT가 주차 범위 안인 것 자동 표시
- **PDF 렌더링**: `infra/pdf/chromeRenderer.js`가 `chrome --headless --print-to-pdf`. 실패 시 envelope JSON으로 에러 회귀
- **PAYLOAD JSON 구조**: 추정 — `{ workItems: [...], routineItems: [...], nextWeekEvents: [...], notes }`
