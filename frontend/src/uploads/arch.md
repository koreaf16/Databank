# DATABANK 화면 구성 설명

IT 서비스 관리 플랫폼 **IT-SCO**의 사용자 화면 구성입니다.

---

## 로그인

앱 최초 진입 시 로그인 화면이 표시됩니다. 로그인 완료 후 홈(대시보드)으로 이동합니다.

---

## 기본 화면 구조

```
┌─────────────┬──────────────────────────────────┐
│             │  상단바 (사용자 아바타 + 알림벨)      │
│  사이드바    ├──────────────────────────────────┤
│  (좌측)     │                                  │
│             │        본문 (현재 페이지)           │
│             │                                  │
└─────────────┴──────────────────────────────────┘
```

채널/피드 화면에서는 사이드바와 상단바가 사라지고 메시지 화면이 전체를 차지합니다.

---

## 사이드바

항상 좌측에 고정된 260px 너비의 내비게이션 패널입니다.

**상단 영역**
- 워크스페이스명: 데이타뱅크시스템즈
- 로그인한 사용자 아바타 (이름 첫 글자)
- 로그아웃 버튼
- 검색창 (⌘K)

**메뉴 섹션** — 아래 페이지로 이동

| 메뉴 | 이동 화면 |
|------|----------|
| 홈 | 대시보드 |
| 메시지 | 채널 랜딩 |
| 일정관리 | 캘린더 |
| 지원이력 | 이력 목록 |
| 지식베이스 | KB 홈 |
| 주간업무보고 | 주간 보고 |
| 점검현황표 | 현황 매트릭스 |
| 관리설정 | 관리자 패널 |

**바로가기 섹션** (접힘/펼침)
- 멘션 & 반응 / 즐겨찾기 / 최근 이력 / 뱅크봇·AI

**담당 고객사 섹션**
- 고객사 목록 (최대 10개 표시)
- 고객사 클릭 → 해당 고객사의 피드 채널로 이동

**프로젝트 섹션**
- 프로젝트 채널 목록
- 클릭 → 해당 프로젝트 피드로 이동

> 모바일에서는 사이드바 대신 하단 탭 바 + 햄버거 메뉴로 대체됩니다.

---

## 홈 (대시보드)

오늘과 이번 주 업무 현황을 한눈에 보여주는 메인 화면입니다.

**상단 KPI 카드 2개**
- 이번 주 전체 일정 건수 (클릭 시 일정관리로 이동)
- 주간 진행률 (완료 건수 / 전체 건수, %)

**오늘의 일정 카드**
- `팀 전체` / `내 일정` 토글 필터
- 일정 목록: 시작 시간, 종료 시간, 제목, 고객사, 담당자, 방문방법, 유형 태그
- 현재 진행 중인 일정은 파란 점 표시 + 시간 강조
- 완료된 일정은 체크 아이콘 + 흐리게 처리
- 우측 상단 "일정표 보기" 링크

**우측 사이드 패널**

| 패널 | 내용 |
|------|------|
| AI 리포트 | 진행률 기반 자동 코멘트 + "주간 상세 분석 보기" 버튼 |
| 엔지니어별 현황 | 각 엔지니어의 주간 정기점검 진행률 (이름 + 프로그레스바) |
| 빠른 이동 버튼 | 주간 보고 / 지식 베이스 |

## 메시지 (채널)

### 채널 랜딩

사이드바에서 채널을 선택하기 전 안내 화면입니다.  
"고객사 채널을 선택해 채널을 열어주세요" 안내 문구와 채널 유형 설명이 표시됩니다.

### 채널 화면

고객사 또는 서버에 연결된 메시지 채널입니다. 상단 탭으로 기능이 구분됩니다.

**탭 구성**

| 채널 유형 | 탭 목록 |
|-----------|---------|
| 일반 서비스 채널 | Conversation / History / Trend / Reports |
| 고객사·그룹 채널 | Conversation / History / Reports |

**Conversation 탭**
- 메시지 목록: 날짜 구분선, 발신자 아바타·이름·시간, 메시지 내용
- 메시지 유형에 따라 시스템 메시지(가운데 정렬)와 일반 메시지 구분
- 스레드 열기 버튼 → 우측에 ThreadPanel 슬라이드인
- AI 버튼 → 우측에 AIPanel 슬라이드인
- 하단 메시지 입력창

**History 탭** — 해당 채널의 지원 이력 목록

**Trend 탭** — 서비스 지표 트렌드 차트 (일반 서비스 채널만)

**Reports 탭** — 생성된 보고서 목록 (건수 뱃지 표시)

---

## 피드 (고객사/프로젝트)

사이드바에서 고객사나 프로젝트를 클릭했을 때 열리는 피드 화면입니다.  
채널 화면과 유사하게 **Conversation / History / Reports** 3개 탭으로 구성됩니다.

URL 형태: `feed:{slug}?serviceId=X&teamId=Y`  
서비스 ID나 팀 ID를 URL 파라미터로 받아 필터링된 뷰를 초기 표시합니다.

---

## 일정관리

주간 캘린더 형태의 일정 관리 화면입니다.

- 7시~21시 시간축의 주간 뷰 (월~일)
- 일정 블록: 색상으로 유형 구분 (파란=정기점검, 노란=기술지원, 빨간=장애처리, 보라=설치)
- **드래그로 일정 이동** 가능
- **하단 핸들 드래그로 종료 시간 조정** 가능
- 일정 클릭 → 상세 정보 팝업
- 새 일정 생성 버튼

**일정 유형 태그**

| 태그 | 색상 |
|------|------|
| 정기점검 | 파랑 |
| 기술지원 | 노랑 |
| 장애처리 | 빨강 |
| 회의 | 보라 |

---

## 지원이력

고객사별 지원 이력을 조회하고 등록하는 화면입니다.

**상단 영역**
- 제목: "지원이력" + 전체 건수
- 모드 전환 버튼: `목록` / `AI 검색`
- `+ 이력 등록` 버튼 → 등록 모달

**통계 카드 4개** (클릭으로 유형 필터링)
- 전체 / 정기점검 / 기술지원 / 장애처리 건수
- 선택된 카드는 링 강조 + "필터 적용 중" 표시

**목록 모드**
- 고객사 필터 / 유형 필터 드롭다운
- 이력 행: 날짜, 고객사, 서버/서비스, 유형 태그, 담당자, 방문방법
- 행 클릭 → 아코디언으로 상세 내용 펼침 (작업 내용, 발견 사항, 조치 사항)

**AI 검색 모드**
- 자연어 검색창
- 벡터 유사도 검색 결과 목록 + 유사도 퍼센트 바

**이력 등록 모달**
- 고객사, 서버, 지원 유형, 날짜, 담당자, 방문방법, 작업 내용, 발견 사항, 권고 사항 입력
- 저장 시 전역 Reports에 보고서 자동 생성

## 지식베이스

사내 기술 문서와 노하우를 정리한 위키 형태의 화면입니다.

**뷰 상태 전환**

| 뷰 | 설명 |
|----|------|
| home | 섹션별 게시판 목록 카드 |
| board | 게시판 내 게시글 목록 |
| post | 게시글 상세 내용 |
| admin | 섹션/게시판 관리 |

**홈 화면**
- 섹션 단위로 게시판 카드 그룹화
- 통합 검색창 — 키워드 입력 후 검색 시 검색 결과 패널 오버레이
  - RAG(AI) 답변이 검색 결과 상단에 표시됨
  - 게시글 결과 목록에 유사도 바 표시
  - 섹션 필터 칩으로 범위 좁히기 가능

**게시글 상세**
- 본문, 첨부파일, 태그, 처리 상태 표시
- 처리 상태: 대기(회색) / 처리중(노랑) / 완료(초록) / 오류(빨강)

---

## 주간업무보고

이번 주 업무 결과를 정리한 보고서 형태 화면입니다.

- 주간 날짜 범위 표시 (월~금)
- 완료된 일정과 지원 이력을 종합해 일별로 접힘/펼침 카드로 표시
- 다음 주 예정 일정 목록
- 일정 유형별 태그 (정기점검, 기술지원, 장애처리 등)
- 방문 방법 표시 (방문 / 원격)

---

## 점검현황표

월별 고객사×서비스 기준으로 점검 진행 현황을 매트릭스로 보여주는 화면입니다.

**상단 컨트롤**
- 월 선택 (이전/다음 화살표)
- `내 담당만` / `전체` 토글

**현황 표시 요소**

| 요소 | 설명 |
|------|------|
| 진행률 링 (SVG) | 완료/전체 비율을 원형 게이지로 표시 |
| 진행률 바 | 가로 막대로 달성률 표시 |
| 상태 점 | 초록=완료, 빨강(깜빡임)=긴급, 회색=예정 |

- 서비스 행 클릭 → 지원 상세 모달 팝업
- 지연/미완료 항목은 빨간 강조

## 관리설정

관리자와 일반 사용자 간 메뉴 구성이 다릅니다.

### 관리자 탭

| 탭 | 내용 |
|----|------|
| 고객사 통합 관리 | 고객사 목록 + 담당 서비스 + 점검 주기 + 배정 현황 |
| 조직도 관리 | 부서 트리 구조, 부서 추가/수정 |
| 사용자 관리 | 직원 목록, 역할·부서 설정 |
| 권한 설정 | 기능별 역할 권한 매트릭스 표 |
| 알림 규칙 | 이벤트별 알림 채널·에스컬레이션 규칙 |
| 데이터 품질 | 데이터 정합성 현황 점검 |

### 일반 사용자 탭

| 탭 | 내용 |
|----|------|
| 나의 담당 서비스 | 본인이 배정된 서비스 목록 |
| 조직도 | 부서 구조 조회 |
| 사용자 목록 | 팀원 목록 조회 |

**모달 패턴**
모든 추가/수정 작업은 슬라이드 모달로 처리됩니다. (고객사, 서비스, 사용자, 부서, 알림규칙 등)

## 공통 UI 요소

**Tag (유형 뱃지)**  
정기점검(파랑) / 기술지원(노랑) / 장애처리(빨강) / 회의(보라) 등 색상 코드 일관 적용

**Support Detail 모달**  
이력 행이나 점검 현황표에서 열리는 팝업. 고객사·서비스·유형·날짜·담당자·방법·요약 정보와 "채널 이동" / "PDF 보고서" 버튼 포함

**알림벨 (상단바)**  
새 알림이 있을 때 뱃지 표시, 클릭 시 알림 목록 드롭다운

**에러 바운더리**  
컴포넌트 오류 발생 시 "다시 시도" 버튼이 있는 인라인 오류 메시지로 대체됨

## 사용자 역할별 차이

| 역할 | 주요 차이 |
|------|----------|
| 관리자 (admin) | 관리설정 전체 탭 접근, 고객사 추가 버튼 노출 |
| 팀장 (manager) | 관리설정 일부 탭, 고객사 추가 버튼 노출 |
| 엔지니어 (engineer) | 담당 고객사만, 이력 입력 가능 |
| 영업 (sales) / 조회 (viewer) | 읽기 위주 |
